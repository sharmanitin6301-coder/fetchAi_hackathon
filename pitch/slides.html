05 / Architecture

How AccessFix Works

A multi-agent, closed-loop pipeline from diagnostic scan to mathematical verification.

Step 1 Scanner Axe audit + ARIA snapshot
Step 2 Task Finder Discovers key visitor goal
Step 3 Blind Agent Keyboard only, identifies trap
Step 4 Prioritizer Scores task-blocking issues
Step 5 Fixer Semantic HTML & CSS repair
Step 6 Verifier Layout shift check + re-test
Step 7 Report Diff + screen-reader audio
🔄 Closed-Loop Verification: If the agent is still stuck or layout shifts > 5px, Verifier loops back to Fixer with targeted context (Max 3 rounds).
LOOP: Step 6 → Step 5
